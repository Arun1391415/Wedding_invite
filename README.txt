SOWMIYA & ARUN — DIGITAL WEDDING INVITATION

FILES
- index.html: complete responsive invitation website.
- engagement-scene.png: 3D illustrated Tamil engagement scene (bride in silk saree, groom in formal attire).

PERSONALISE
1. Open index.html in Chrome.
2. Tap each “Add ... photo” link and choose a photo from your phone/computer.
3. Tap “ADD MUSIC” and choose a Tamil instrumental audio file that you own or have permission to use.
4. The chosen photos/music are loaded locally in that browser session. They are NOT embedded in the hosted page. To make them visible to everyone, place the image/audio files in the website folder and update the corresponding image src and audio source in index.html, or ask a developer to wire them in.
5. Venue is currently shown as “Venue details to be announced”; edit the venueText element in index.html when confirmed.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. sowmiya-arun-invite.
3. Upload index.html (and any photo/audio files you have added).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”, select “main” and “/ (root)”, then Save.
6. Wait for the Pages URL to appear. It will look like https://YOUR-USERNAME.github.io/sowmiya-arun-invite/
7. Open the link on a phone to test it, then share it on WhatsApp.

ALTERNATIVE: NETLIFY DROP
1. Put index.html and any final photo/audio assets into one folder.
2. Open https://app.netlify.com/drop and sign in.
3. Drag the folder into the page. Netlify will publish it and provide a shareable URL.

IMPORTANT
- The wedding date is set to 10 February 2027; engagement date is 1 November 2026.
- No venue was supplied, so a placeholder is displayed.
- No personal photos were supplied, so the page uses a generated 3D illustration for the Tamil engagement scene and illustrated placeholders for other memories. Photo-upload controls are included.

- The photo-upload controls preview images only on the device/browser where selected. For a public invitation, replace them with hosted image file paths before publishing.
